# Mogged Keyboard

Своя клавиатура для Android в стиле **Material You**.
Набранный текст остаётся на устройстве; интернет — только для обновлений.

## Что умеет

- Раскладки **русская + английская**, переключение клавишей 🌐
- Shift: одно нажатие — заглавная, второе — Caps Lock, третье — выкл.
- Backspace с удержанием (удаляет подряд)
- Страница цифр и символов (`?123` / `ABC`)
- Долгое нажатие: **е → ё**, **ь → ъ**, **ъ → ь**
- Заглавная буква после точки (можно выключить)
- Вибрация и звук нажатий, регулировка высоты
- **Обновление из самого приложения**: кнопка «Проверить обновления»
  скачивает новый APK с GitHub и открывает установщик
- **Material You**: цвета из системной палитры (Android 12+)

## Адаптивность

- Android **8.0+** (minSdk 26)
- Размеры считаются от экрана: кегль и высота клавиш подстраиваются
- Учитываются **навигационная панель, жесты и вырез экрана** (через WindowInsets)
- На планшетах и складных клавиатура не растягивается шире 720dp
- Альбомная ориентация: высота ограничена половиной экрана

## Структура

```
app/src/main/java/com/mogged/keyboard/
  MoggedKeyboardService.kt  — клавиатура (ввод, клавиши, цвета, inset'ы)
  Layouts.kt                — раскладки RU / EN / символы
  UpdateManager.kt          — проверка и скачивание обновлений
  MainActivity.kt           — настройки, статус, кнопка обновления
  Prefs.kt                  — настройки
  MoggedApp.kt              — динамические цвета
```

## Первая сборка (один раз)

1. Добавьте секрет с паролем ключа:
   репозиторий → **Settings** → **Secrets and variables** → **Actions** →
   **New repository secret** → имя `KEYSTORE_PASSWORD`, значение — любой
   длинный пароль. Запомните его, он же пароль ключа.
2. **Actions** → **Signing setup** → **Run workflow**. Workflow создаст
   `keystore/mogged.jks` и закоммитит его.
3. **Actions** → **Build APK** → **Run workflow**.
4. Скачайте APK из артефакта **MoggedKeyboard-apk** и установите.

С этого момента все сборки подписаны **одним ключом**, поэтому новые
версии ставятся поверх старых: настройки и включённая клавиатура
сохраняются.

## Обновления

Каждая сборка публикуется в **Releases** (тег `latest`) с файлами
`MoggedKeyboard.apk` и `version.json`.

В приложении: карточка «Обновления» → **Проверить обновления**.
Если версия новее — кнопка скачает APK и откроет системный установщик.
Первый раз Android попросит разрешить установку из этого приложения.

Автопроверка включается переключателем «Проверять обновления».

## Заливка изменений с телефона

```
cd /storage/emulated/0/Download/MoggedKeyboard
GITHUB_TOKEN=токен GITHUB_USER=логин sh upload-to-github.sh
```

Токен: classic, права `repo` + `workflow`.
Скрипт обновит файлы и запустит сборку (если ключ подписи уже создан).

## Сборка локально

```
gradle assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`
