# Mogged Keyboard

Своя клавиатура для Android в стиле **Material You**.
Набранный текст остаётся на устройстве; интернет — только для обновлений.

## Что умеет

- Раскладки **русская + английская**, переключение клавишей 🌐
- Shift: одно нажатие — заглавная, второе — Caps Lock, третье — выкл.
- Backspace с удержанием; удаляет по кодпоинтам (эмодзи не ломаются)
- Страница цифр и символов (`?123` / `ABC`)
- Долгое нажатие: **е → ё**, **ь → ъ**
- Автозаглавная по флагам поля, после `.` `?` `!` и перевода строки
- Enter по `imeOptions`: поиск / отправить / далее / готово
- Почта и адреса: на нижнем ряду появляются `@` и `/`
- Пароли: без автозаглавной и без подсказок
- Вибрация и звук нажатий, регулировка высоты
- **Обновление из приложения** + список изменений («Что нового»)
- **Material You**: цвета из системной палитры (Android 12+)

## Адаптивность

- Android **8.0+** (minSdk 26)
- Кегль и высота клавиш считаются от экрана
- Учитываются **навигационная панель, жесты и вырез** (WindowInsets)
- На планшетах и складных ширина не больше **720dp**, по центру
- Split-screen и поворот: размеры пересчитываются на лету
- Поворот и смена темы не сбрасывают Shift, Caps и страницу символов

## Ключ подписи

Ключ **не лежит в репозитории** — только в секретах GitHub Actions.
Без одного и того же ключа Android не поставит обновление поверх
установленного приложения, поэтому ключ создаётся **один раз** и
дальше только используется.

> Если ключ когда-то лежал в репозитории (`keystore/mogged.jks`),
> он считается **скомпрометированным**: его мог скачать кто угодно.
> В этом случае создаётся новый ключ, а старый больше не используется.
> `upload-to-github.sh` сам удаляет из текущей ветки старый ключ,
> `log.zip` и `buildlog/`, но в истории коммитов они остаются —
> поэтому важно именно заменить ключ, а не пытаться «спрятать» старый.

### Один раз: создать ключ

В Termux:

```sh
pkg update && pkg install openjdk-17
cd /storage/emulated/0/Download/MoggedKeyboard
sh tools/make-keystore.sh
```

Если `openjdk-17` не находится в репозитории Termux, ключ можно
создать через OpenSSL — скрипт сам выберет доступный инструмент:

```sh
pkg install openssl
sh tools/make-keystore.sh
```

Скрипт спросит пароль и создаст:

- `tools/mogged.jks` — сам ключ
- `tools/mogged.b64` — он же в base64 для секрета

Оба файла игнорируются git и не загружаются скриптом.
**Сделай резервную копию `mogged.jks`.** Если ключ потерян —
обновления перестанут ставиться, пользователям придётся переустанавливать.

### Один раз: добавить секреты

Открой:

```
github.com/itzme-work/MoggedKeyboard/settings/secrets/actions/new
```

Добавь два секрета:

| Имя | Значение |
|---|---|
| `KEYSTORE_PASSWORD` | пароль, который ввёл в скрипте |
| `KEYSTORE_BASE64` | всё содержимое `tools/mogged.b64` одной строкой |

Скопировать base64 в буфер обмена Termux:

```sh
termux-clipboard-set < tools/mogged.b64
```

### Один раз: залить и собрать

```sh
cd /storage/emulated/0/Download/MoggedKeyboard
GITHUB_TOKEN=токен GITHUB_USER=itzme-work sh upload-to-github.sh
```

Токен: classic, права `repo` + `workflow`.
Скрипт проверит, что оба секрета на месте, зальёт файлы и запустит
сборку. Если секретов нет — остановится и скажет, чего не хватает.

Если раньше уже стояла сборка, подписанная **другим** ключом
(например, первая отладочная), её нужно один раз удалить.
Дальше все версии подписаны одним ключом и ставятся поверх.

## Обновления

Каждая сборка:

1. получает `versionCode` = номер запуска GitHub Actions;
2. публикуется в **Releases** (тег `latest`) с файлами
   `MoggedKeyboard.apk` и `version.json`;
3. в `version.json` лежат `versionCode`, `versionName`, название
   релиза, список изменений и `sha256` APK.

В приложении карточка «Обновления»:

- сравнивает версии **по versionCode**;
- качает APK только по **HTTPS** и только с хостов GitHub;
- сверяет **SHA-256** с `version.json` до открытия установщика;
- сообщает об обрыве загрузки, нехватке места и несовпадении хеша;
- перед скачиванием показывает список изменений новой версии.

Автопроверка включается переключателем «Проверять обновления».

## Версии и названия

| Версия | Название | Коротко |
|---|---|---|
| 0.2.0 | «Тихий старт» | безопасность, поведение ввода, список изменений |
| 0.1.0 | «Первый запуск» | первая рабочая клавиатура |

Полный список — в приложении, карточка «Что нового» (`Changelog.kt`).

`versionName` задаётся в `app/build.gradle.kts`, `versionCode` — в CI.
Номер запуска растёт, поэтому каждая новая сборка считается новее.

## Структура

```
app/src/main/java/com/mogged/keyboard/
  MoggedKeyboardService.kt  — клавиатура (ввод, клавиши, цвета, inset'ы)
  Layouts.kt                — раскладки RU / EN / символы
  UpdateManager.kt          — проверка, скачивание, SHA-256
  MainActivity.kt           — настройки, статус, обновления, changelog
  Changelog.kt              — список обновлений
  Prefs.kt                  — настройки
  MoggedApp.kt              — динамические цвета
release.json                — данные релиза для version.json
.github/workflows/build.yml — сборка, lint, публикация
tools/make-keystore.sh      — одноразовое создание ключа
```

## Сборка локально

```
gradle assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`

Без `KEYSTORE_PATH` и `KEYSTORE_PASSWORD` APK соберётся, но не подпишется.
