# Mogged Keyboard

<img src="docs/icon-512.png" width="128" alt="Значок Mogged Keyboard">

Клавиатура для Android в стиле Material You: русская и английская раскладки,
своё оформление, жесты, шаблоны и история буфера. Набранный текст остаётся
на телефоне; сеть нужна только для проверки обновлений.

## Возможности

- **Две раскладки**, RU и EN, переключение клавишей 🌐; долгое нажатие —
  системный выбор клавиатуры
- **Shift**: тап — одна заглавная, второй тап — Caps Lock, долгое — сразу
  Caps Lock; буквы на клавишах показываются заглавными
- **Долгое нажатие на букве или знаке** — меню альтернатив (ё, ъ, акценты,
  валюты, кавычки); подсказки символов можно выключить
- **Страницы цифр и символов** (`?123`, `=<`), необязательный числовой ряд
- **Жесты**: двойной пробел — точка и пробел; свайп по пробелу — смена языка
  или движение курсора; свайп влево по Backspace — удаление слова
- **Панель инструментов** над клавишами: выделить всё, копировать, вырезать,
  вставить, история, отмена и повтор, курсор, одна рука, инкогнито,
  настройки; состав и порядок настраиваются, подписи — по долгому нажатию
- **Квадратная кнопка режима** слева над клавишами: нажатие переключает
  «Инструменты» и «Быстрые вставки», долгое — сворачивает строку.
  В «Быстрых вставках» до пяти чипов: последние записи истории или шаблоны
- **История буфера** (по умолчанию выключена): до 30 записей и 10
  закреплённых, шифрование системным ключом устройства, срок 1 час / 1 день / никогда;
  закреплённые помечены значком и фоном, свайп удаляет, поиск — в настройках
- **Шаблоны**: сокращение раскрывается по пробелу, до 50 заготовок
- **Умная пунктуация** (по умолчанию выключена): кавычки, тире, многоточие,
  пробел после знака; не работает в адресах, почте, путях и паролях
- **Режим инкогнито** и автоматическое отключение подсказок в полях паролей
- **Оформление**: темы (системная, светлая, тёмная, AMOLED), акцент из обоев
  или свой, шесть пресетов, формы клавиш, тень, прозрачность, своя картинка
  фона с затемнением и размытием, мини-предпросмотр
- **Размеры**: ширина 50–100%, отступ у краёв 0–12 dp, режим одной руки,
  масштаб шрифта, отдельная высота для планшета
- **Отклик**: четыре характера вибрации и свой, звук с отдельной громкостью,
  предпросмотр клавиши, учёт системного «Удалить анимации»
- **Резервная копия настроек** в JSON и «Песочница» для проверки клавиатуры
- **Обновление из приложения** со списком изменений

## Приватность

- Всё хранится **на устройстве**: настройки — в приватной папке приложения,
  автобэкап выключен, в облако ничего не уходит.
- **Сеть только для обновлений**: HTTPS, хосты GitHub, проверка SHA-256
  и сертификата подписи.
- **История буфера** по умолчанию выключена и зашифрована системным ключом
  устройства; ключ работает только на разблокированном телефоне.
- В историю **не попадают**: пароли, PIN, числа, телефоны, почта,
  одноразовые коды из СМС (правило можно отключить), копии, помеченные
  приватными, и всё, что скопировано в инкогнито.
- Копия, лежавшая в буфере до открытия панели, сохраняется только по кнопке
  «Сохранить».
- Резервная копия содержит настройки и шаблоны **открытым текстом**;
  история буфера в неё не входит.

## Установка и обновления

1. Скачайте `MoggedKeyboard.apk` из раздела [Releases](https://github.com/itzme-work/MoggedKeyboard/releases) этого репозитория.
2. Разрешите установку из этого источника, когда система спросит.
3. Дальше обновления приходят из приложения: «Ещё → Обновления».

Первая установка поверх сборки, подписанной другим ключом, невозможна —
её нужно один раз удалить.

## Официальные сборки

Официальные сборки — **только** файлы из [Releases](https://github.com/itzme-work/MoggedKeyboard/releases) этого репозитория.
Отпечаток SHA-256 сертификата подписи:

```
0D:55:0E:15:69:9A:8D:29:DD:AE:D1:04:9E:01:8A:9D:
68:B7:2D:38:CB:26:A5:2B:12:3A:4F:6F:64:B2:47:E1
```

Тот же отпечаток без двоеточий лежит в `version.json` релиза (`certSha256`).
Проверить скачанный файл можно на компьютере:

```sh
apksigner verify --print-certs MoggedKeyboard.apk
```

Строка `certificate SHA-256 digest` должна совпасть с отпечатком выше.
В приложении раздел «Ещё → О приложении» показывает, официальная ли это
сборка: свой отпечаток сравнивается с опубликованным.

Форки и изменённые копии — не наши сборки. Не вводите в них пароли,
не устанавливайте их обновления и не сообщайте о них как об ошибках
этого проекта.

## Совместимость

- Android **8.0 и новее**.
- Телефоны и планшеты: от 600 dp по ширине клавиши выше, есть отдельная
  высота по умолчанию; поворот и смена размера окна пересчитывают размеры.
- Учитываются жесты навигации, вырез экрана и системная панель.
