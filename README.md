# Mogged Keyboard

Своя клавиатура для Android в стиле **Material You**.
Набранный текст остаётся на устройстве; интернет — только для обновлений.

## Что умеет

- Раскладки **русская + английская**, переключение клавишей 🌐
- Долгое нажатие на 🌐 — системный выбор клавиатуры
- Shift: тап — одна заглавная, быстрый второй тап — Caps Lock, долгое нажатие — сразу Caps Lock
- Буквы на клавишах показываются заглавными при Shift и Caps Lock
- **Долгое нажатие на любой букве или знаке** — всплывающее меню альтернатив
  (ё, ъ, акценты, валюты, кавычки)
- **Подсказки символов** в углу клавиш (можно выключить)
- Страница цифр и символов (`?123`), вторая страница `=<`:
  валюты, типографика, математика
- Необязательный **числовой ряд** над буквами
- **Двойной пробел** ставит точку и пробел
- **Свайп по пробелу** настраивается: смена языка, движение курсора (шаг 12dp)
  или выключен; долгое нажатие на пробеле всё равно меняет язык
- **Свайп влево по Backspace** стирает слово, удержание — по символу
- **Кнопка смены языка** включается и выключается; без неё пробел занимает её место
- **Контур клавиш** и масштаб шрифта клавиш **80–120%**
- **Долгое нажатие на Enter** — панель одной руки: слева, справа или выкл
- Предпросмотр клавиши при нажатии
- **Векторные иконки** Shift, Backspace, языка и Enter; у Shift три формы состояния
- Цвета клавиш по ролям: буквы, функциональные, Enter, пробел и активный Shift
- **Пять разделов** в приложении: Главная, Вид, Ввод, Отклик, Ещё
- На телефоне разделы переключает нижняя панель, на широком экране — боковая рейка
- **Живой мини-предпросмотр** ширины, одной руки, радиуса, контура и цветов
- Поле проверки клавиатуры закреплено над нижней навигацией: оно не уезжает при прокрутке
- Бейдж на «Ещё» и карточка на «Главной», когда есть обновление
- Сброс раздела и всех настроек с подтверждением
- Темы: системная, светлая, тёмная, **AMOLED**
- Радиус клавиш, **ширина 50–100%** и **режим одной руки** (блок к левому или правому краю)
- Четыре характера вибрации — **клик, тик, сильный и свой**;
  у «Своего» настраиваются длительность и сила, плюс отклик при отпускании
- Громкость звука настраивается отдельно
- **Резервная копия настроек**: экспорт и импорт JSON через системный выбор файла
- Backspace с удержанием; удаляет по кодпоинтам (эмодзи не ломаются)
- Автозаглавная по флагам поля, после «. », «? » и «! » и перевода строки
- Enter по `imeOptions`: поиск / отправить / далее / готово
- Почта и адреса: на нижнем ряду появляются `@` и `/`
- Пароли: без автозаглавной, подсказок и предпросмотра
- **Экран первого запуска**: включить → выбрать → разрешить установку
- **Обновление из приложения** + список изменений («Что нового»)
- **Material You**: цвета из системной палитры (Android 12+)

## Адаптивность

- Android **8.0+** (minSdk 26)
- Кегль и высота клавиш считаются от экрана
- Учитываются **навигационная панель, жесты и вырез** (WindowInsets)
- На планшетах и складных ширина не больше **720dp**, по центру
- Split-screen и поворот: размеры пересчитываются на лету
- Поворот и смена темы не сбрасывают Shift, Caps и страницу символов

## Ключ подписи

Ключ **не лежит в репозитории** — только в секретах GitHub Actions.
Без одного и того же ключа Android не поставит обновление поверх
установленного приложения, поэтому ключ создаётся **один раз** и
дальше только используется.

> Если ключ когда-то лежал в репозитории (`keystore/mogged.jks`),
> он считается **скомпрометированным**: его мог скачать кто угодно.
> В этом случае создаётся новый ключ, а старый больше не используется.
> `upload-to-github.sh` сам удаляет из текущей ветки старый ключ,
> `log.zip` и `buildlog/`, но в истории коммитов они остаются —
> поэтому важно именно заменить ключ, а не пытаться «спрятать» старый.

### Один раз: создать ключ

В Termux:

```sh
pkg update && pkg install openjdk-17
cd /storage/emulated/0/Download/MoggedKeyboard
sh tools/make-keystore.sh
```

Если `openjdk-17` не находится в репозитории Termux, ключ можно
создать через OpenSSL — скрипт сам выберет доступный инструмент:

```sh
pkg install openssl
sh tools/make-keystore.sh
```

Скрипт спросит пароль и создаст:

- `tools/mogged.jks` — сам ключ
- `tools/mogged.b64` — он же в base64 для секрета

Оба файла игнорируются git и не загружаются скриптом.
**Сделай резервную копию `mogged.jks`.** Если ключ потерян —
обновления перестанут ставиться, пользователям придётся переустанавливать.

### Один раз: добавить секреты

Открой:

```
github.com/itzme-work/MoggedKeyboard/settings/secrets/actions/new
```

Добавь два секрета:

| Имя | Значение |
|---|---|
| `KEYSTORE_PASSWORD` | пароль, который ввёл в скрипте |
| `KEYSTORE_BASE64` | всё содержимое `tools/mogged.b64` одной строкой |

Скопировать base64 в буфер обмена Termux:

```sh
termux-clipboard-set < tools/mogged.b64
```

### Один раз: залить и собрать

```sh
cd /storage/emulated/0/Download/MoggedKeyboard
GITHUB_TOKEN=токен GITHUB_USER=itzme-work sh upload-to-github.sh
```

Токен: classic, права `repo` + `workflow`.
Первый запуск с переменными сохранит токен и логин в
`~/.mogged-token` и `~/.mogged-user` (права 600), и дальше хватает:

```sh
sh upload-to-github.sh
```

Скрипт проверит, что оба секрета на месте, зальёт файлы и запустит
сборку. Если секретов нет — остановится и скажет, чего не хватает.
Флаг `NO_BUILD=1` заливает файлы без запуска сборки.

Если раньше уже стояла сборка, подписанная **другим** ключом
(например, первая отладочная), её нужно один раз удалить.
Дальше все версии подписаны одним ключом и ставятся поверх.

## Обновления

Каждая сборка:

1. проходит **юнит-тесты** и **lint**;
2. получает `versionCode` = номер запуска GitHub Actions;
3. публикуется в **Releases** (тег `latest`) с файлами
   `MoggedKeyboard.apk` и `version.json`;
4. в `version.json` лежат `versionCode`, `versionName`, название
   релиза, список изменений и `sha256` APK.

В приложении карточка «Обновления»:

- сравнивает версии **по versionCode**;
- качает APK только по **HTTPS** и только с хостов GitHub;
- проверяет **хост каждого редиректа** по списку разрешённых;
- сверяет **SHA-256** с `version.json` до открытия установщика;
- сообщает об обрыве загрузки, нехватке места и несовпадении хеша;
- перед скачиванием показывает список изменений новой версии.

Автопроверка включается переключателем «Проверять обновления».

## Версии и названия

| Версия | Название | Коротко |
|---|---|---|
| 0.7.0 | «Жесты и клавиши» | режимы пробела, удаление слова, контур, свой отклик |
| 0.6.0 | «Красота» | векторные иконки, роли цвета, пять разделов, мини-предпросмотр |
| 0.5.0 | «Удобство» | ширина и одна рука, характер вибрации, резервная копия |
| 0.4.0 | «Отклик» | альтернативы, вторая страница символов, жесты, тесты |
| 0.3.0 | «Настройка» | темы, радиус, ползунки, первый запуск |
| 0.2.0 | «Тихий старт» | безопасность, поведение ввода, список изменений |
| 0.1.0 | «Первый запуск» | первая рабочая клавиатура |

Полный список — в приложении, карточка «Что нового» (`Changelog.kt`).

`versionName` задаётся в `app/build.gradle.kts`, `versionCode` — в CI.
Номер запуска растёт, поэтому каждая новая сборка считается новее.

## Тесты

```sh
gradle testReleaseUnitTest
```

- `TextStateTest` — Shift / Caps Lock, автозаглавная, начало предложения;
- `LayoutsTest` — раскладки RU / EN, числовой ряд, вторая страница
  символов, альтернативы у всех клавиш;
- `WidthsTest` — расчёт ширины блока клавиш и режим одной руки;
- `HapticsTest` — характеры вибрации и усиление на Shift, Enter и пробеле;
- `BackupTest` — экспорт и импорт настроек, ограничение значений,
  чужие и битые файлы.

В CI тесты и `lintRelease` идут до сборки APK: красный тест или lint
не пропускают релиз. Отдельный workflow `check.yml` гоняет то же самое
на каждый push и pull request, а `build.yml` остаётся ручным.

## Архив проекта

Локального `zip` в Android нет, поэтому архив собирает сам GitHub —
это ровно содержимое ветки `main`:

```sh
sh tools/make-zip.sh
```

Файл появится рядом с проектом:
`Download/MoggedKeyboard/MoggedKeyboard-<версия>.zip`.
`upload-to-github.sh` делает архив сам после каждой заливки.

## Сборка локально

```
gradle assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`

Без `KEYSTORE_PATH` и `KEYSTORE_PASSWORD` APK соберётся, но не подпишется.
