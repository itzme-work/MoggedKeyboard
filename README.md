# Mogged Keyboard

Своя клавиатура для Android в стиле **Material You**.
Без интернета, без сбора данных, без лишних функций.

## Что умеет

- Раскладки **русская + английская**, переключение клавишей 🌐
- Shift: одно нажатие — заглавная, второе — Caps Lock, третье — выкл.
- Backspace с удержанием (удаляет подряд)
- Страница цифр и символов (`?123` / `ABC`)
- Долгое нажатие: **е → ё**, **ь → ъ**, **ъ → ь**
- Заглавная буква после точки (можно выключить)
- Вибрация и звук нажатий (можно выключить)
- Регулировка высоты клавиатуры
- **Material You**: цвета берутся из системной палитры (Android 12+),
  на старых версиях — базовая палитра Material 3

## Чего нет (специально)

- Нет разрешения на интернет — приложение физически не может ничего отправить
- Нет словаря и «предсказания слов»
- Нет эмодзи-панели (в системе есть своя)

## Структура

```
app/src/main/java/com/mogged/keyboard/
  MoggedKeyboardService.kt  — сама клавиатура (ввод, клавиши, цвета)
  Layouts.kt                — раскладки RU / EN / символы
  MainActivity.kt           — экран настройки и включения
  Prefs.kt                  — настройки
  MoggedApp.kt              — подключение динамических цветов
  res/xml/method.xml        — регистрация IME
```

## Сборка APK через GitHub Actions (без компьютера)

1. Создайте пустой репозиторий `MoggedKeyboard` на github.com.
2. Залейте туда файлы проекта. Самый простой способ с телефона —
   скрипт `upload-to-github.sh` (нужен curl, он в Android есть):

   ```
   GITHUB_TOKEN=ваш_токен GITHUB_USER=ваш_логин sh upload-to-github.sh
   ```

   Токен: Settings → Developer settings → Personal access tokens →
   Tokens (classic) → права `repo` и `workflow`.
   После заливки токен можно удалить.

3. Откройте вкладку **Actions** → сборка **Build APK** запустится сама
   (или нажмите **Run workflow**). Через 3–5 минут внутри сборки
   появится артефакт **MoggedKeyboard-apk** — это и есть APK.

4. Скачайте APK на телефон, откройте, разрешите установку из этого
   источника.

## Включение клавиатуры

1. Откройте Mogged Keyboard.
2. **Включить клавиатуру** → включите Mogged Keyboard в списке.
3. **Выбрать клавиатуру** → выберите Mogged Keyboard.
4. Нажмите на любое поле ввода.

## Как менять цвета

Ничего менять не нужно: на Android 12+ цвета берутся из обоев.
Хотите свою палитру — правьте `ic_launcher_background` и
`loadColors()` в `MoggedKeyboardService.kt`.

## Как добавить язык

В `Layouts.kt` добавьте функцию по образцу `russian()` и ветку в
`page()`; в `MoggedKeyboardService.switchLang()` — переключение по кругу.

## Сборка локально (если есть компьютер)

```
gradle assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`
