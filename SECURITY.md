# Безопасность Mogged Keyboard

## Что поддерживается

Исправления выходят только для **последней опубликованной версии**
(карточка «Обновления» и раздел Releases). Перед сообщением об ошибке
обновитесь: возможно, она уже исправлена.

## Куда сообщать

Приватно, не в Issues:

**https://github.com/itzme-work/MoggedKeyboard/security/advisories/new**

Эта форма доступна, если в настройках репозитория включено
«Private vulnerability reporting». Если форма недоступна, откройте Issue
без подробностей с просьбой связаться — детали пришлём в ответ.

Пожалуйста, **не публикуйте** рабочий способ атаки до выхода исправления.

## Что полезно приложить

- версию приложения (`Настройки → Ещё → О приложении`) и версию Android,
  модель телефона;
- что происходит и как повторить;
- для проблем с обновлением — отпечаток сертификата из `version.json`
  и `sha256` скачанного файла;
- если есть — короткое видео или снимок экрана без ваших личных данных.

## Ожидаемые сроки

- подтверждение получения — до 3 рабочих дней;
- первая оценка и решение (принять / не воспроизводится) — до 7 дней;
- исправление — в ближайшем обновлении; о выходе сообщим в том же отчёте.

Это личный проект, не компания: сроки выполняются по возможности, но мы
стараемся уложиться в указанные.

## Область проверки

Клавиатура, её настройки, история буфера, резервная копия, канал
обновлений (HTTPS, список хостов GitHub, SHA-256 и сверка сертификата),
хранение ключей в Keystore.

Вне области: атаки, требующие root или разблокированного загрузчика;
фишинговые копии в магазинах и сторонние сборки (о них сообщайте в GitHub
и в магазин); неофициальные сборки, собранные из форка.

## Официальные сборки

Скачивайте APK только из **Releases** этого репозитория. Отпечаток
сертификата опубликован в README и в `version.json` каждого релиза;
приложение показывает в разделе «Ещё», официальная ли это сборка.
